Подробная инструкция по запуску проекта
Проект представляет собой веб-приложение для автоматизации учёта студентов и успеваемости в колледже, разработанное на Python с использованием фреймворка Flask.

1. Требования к системе
Операционная система: Windows (инструкция для Windows)

Установленный Python версии 3.9 или выше

Доступ к командной строке (cmd, PowerShell)

2. Подготовка проекта
Если у вас есть архив с проектом, распакуйте его в удобную папку. Например: D:\programmirovanie\college_admin\college_admin.

3. Создание виртуального окружения
Виртуальное окружение позволяет изолировать зависимости проекта от других Python-проектов на компьютере.

Откройте командную строку (Win+R → cmd → Enter).

Перейдите в папку проекта:

cmd
cd D:\programmirovanie\college_admin\college_admin
Создайте виртуальное окружение:

cmd
python -m venv venv
(Если у вас Python 3.11, команда python может быть python3 или py -3.11. Обычно работает python.)

Активируйте виртуальное окружение:

cmd
venv\Scripts\activate
В командной строке должно появиться (venv) в начале строки.

4. Установка зависимостей
В проекте должен присутствовать файл requirements.txt. Если его нет – создайте его вручную (см. ниже). Установите все необходимые библиотеки:

cmd
pip install -r requirements.txt
Если файла requirements.txt нет, создайте его со следующим содержимым:

text
Flask==2.3.3
Flask-SQLAlchemy==3.1.1
Flask-Login==0.6.2
Flask-WTF==1.2.1
WTForms==3.1.1
SQLAlchemy==2.0.23
pandas==2.1.4
openpyxl==3.1.2
python-dotenv==1.0.0
Затем выполните установку командой выше.

5. Инициализация базы данных
Перед первым запуском необходимо создать базу данных и заполнить её начальными данными (администратор, тестовые группы, предметы, студенты, оценки). Для этого используется скрипт migrate.py.

Выполните в командной строке:

cmd
python migrate.py
Скрипт создаст файл college.db в корневой папке проекта, создаст таблицы и заполнит их тестовыми данными. После успешного выполнения вы увидите сообщение:

text
✅ БАЗА ДАННЫХ УСПЕШНО СОЗДАНА!
...
🔑 ДАННЫЕ ДЛЯ ВХОДА:
   Логин: admin
   Пароль: admin123
Если скрипт не создан, вы можете создать базу данных вручную, запустив интерпретатор Python и выполнив:

python
from app.init_ import db, create_app
app = create_app()
with app.app_context():
    db.create_all()
Но проще использовать готовый скрипт.

6. Запуск приложения
Запустите сервер разработки:

cmd
python run.py
Если всё настроено правильно, вы увидите сообщение:

text
 * Serving Flask app 'app.init_'
 * Debug mode: on
 * Running on http://127.0.0.1:5000 (Press CTRL+C to quit)
Теперь откройте браузер и перейдите по адресу: http://localhost:5000

Вы будете перенаправлены на страницу входа.

7. Вход в систему
Логин: admin

Пароль: admin123

После входа откроется панель управления (дашборд).

8. Возможные проблемы и их решение
Ошибка: "No module named 'app'"
Убедитесь, что вы находитесь в папке, где лежит файл run.py. Если структура папок отличается, проверьте путь.

Ошибка: "Could not build url for endpoint 'main.grades'"
Такая ошибка возникала ранее, но должна быть исправлена в коде. Убедитесь, что в routes.py есть функция grades().

Ошибка при выполнении migrate.py
Убедитесь, что виртуальное окружение активировано.

Проверьте наличие всех зависимостей (pip list).

Если скрипт migrate.py отсутствует, создайте его из текста, приведённого в предыдущих сообщениях.

Ошибка доступа к порту 5000
Порт 5000 может быть занят другим приложением (например, службой WSL). Можно изменить порт, указав его при запуске:

cmd
python run.py --port=5001
Но в файле run.py обычно прописано port=5000. Чтобы изменить, отредактируйте строку:

python
app.run(debug=True, host='0.0.0.0', port=5000)  # изменить 5000 на другой порт
Не работает кнопка "Экспорт" или ошибка при экспорте
Убедитесь, что папка exports существует и доступна для записи. Скрипт migrate.py создаёт её автоматически. Если нет – создайте вручную папку exports в корне проекта.

9. Остановка приложения
В командной строке нажмите Ctrl+C, чтобы остановить сервер.

10. Дополнительные советы
Для выхода из виртуального окружения выполните deactivate.

Если вы изменяете код, сервер разработки автоматически перезагрузится (благодаря debug=True).

Для просмотра структуры базы данных можно использовать SQLite Studio или любой другой клиент SQLite.
