    API ключ
    API ключ используется для аутентификации при вызовах API из внешних систем. Храните его в безопасности и не делитесь публично.
    Нажмите "Копировать" чтобы скопировать ключ в буфер обмена
    Внимание! При генерации нового ключа старый станет недействительным. Все приложения, использующие старый ключ, потеряют доступ к API.
    Документация API
    Основы работы с API

    Все запросы к API должны включать заголовок авторизации:

    Authorization: Bearer ваш_api_ключ

    Базовый URL для всех запросов:

    {{ request.host_url }}api/
    Доступные endpoint'ы
    GET /api/students

    Получение списка студентов с пагинацией

    Параметры:
    • page - номер страницы (по умолчанию: 1)
    • per_page - элементов на странице (по умолчанию: 20)
    • group - фильтр по ID группы
    • gender - фильтр по полу (M/F)
    GET /api/grades

    Получение списка оценок

    Параметры:
    • student_id - фильтр по ID студента
    • subject_id - фильтр по ID предмета
    • date_from - фильтр по дате начала
    • date_to - фильтр по дате окончания
    GET /api/stats

    Получение статистики системы

    Не требует параметров

    GET /api/settings
