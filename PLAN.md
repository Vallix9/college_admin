# План доработки проекта College Admin

Решения приняты: **полная доработка**, **venv + requirements.txt**, **структуру файлов не менять**
(роуты остаются в `app/routes.py`, модели в `app/models.py`), **сид-данные + пароль админа из `.env`**.

## Правила работы

1. Идём по фазам строго по порядку. Фаза не закрыта, пока не проверена.
2. Перед каждой фазой — `git`-подобный контроль: снимок изменённых файлов в `_backup/<дата>/`
   (репозиторий git в проекте отсутствует, поэтому делаем ручные копии).
3. После каждой фазы — запуск приложения и ручной прогон затронутых страниц.
4. Ничего не удаляем без явной необходимости; старые/дублирующие куски помечаем и убираем
   только после того, как новое работает.
5. Комментарии в код пишем только там, где логика неочевидна (по правилам проекта комментарии
   не добавляются без нужды).

## Порядок и зависимости

```
Фаза 0 (окружение)      → нужно для любой проверки
Фаза 1 (блокеры)        → без неё ничего не запускается
Фаза 2 (логирование)    → нужно для Фазы 4.4 и Фазы 6
Фаза 3 (логика)         → чинит то, что уже работает
Фаза 4 (функционал)     → использует логирование из Фазы 2
Фаза 5 (роли)           → влияет на все страницы, идёт после 3 и 4
Фаза 6 (аудит)          → пишет в логи/БД, идёт после 2 и 5
Фаза 7 (безопасность)   → финальная зачистка, идёт после 5
Фаза 8 (Docker)         → после того, как всё работает локально
Фаза 9 (тесты/дока)     → закрывает проект
```
