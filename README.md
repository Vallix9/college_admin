# College Admin — система управления учебным процессом колледжа

Веб-приложение для администратора учебного отдела: студенты, группы, расписание,
журнал успеваемости, посещаемость, итоги, учётные записи и кабинет студента.

## Возможности

- Студенты: добавление, правка, удаление, фильтры по группе/полу/статусу,
  карточка с историей оценок, средний балл и посещаемость.
- Учебные группы, предметы, расписание, календарные периоды (семестры).
- Журнал: сетка «студенты × даты занятий», оценки, пропуски с причинами,
  массовая отметка, история изменений оценок.
- Итоги за период: допуск, рекомендация, ручной итог; сводка по группам.
- Отчёты и выгрузка в Excel: журнал, посещаемость, итоги, пароли студентов.
- Импорт данных из Excel/CSV: студенты, группы, оценки, настройки.
- Роли: администратор, преподаватель (только свои группы), студент (кабинет);
  CSRF-защита, аудит действий, заголовки безопасности, ограничение попыток входа.
- Резервные копии и восстановление базы, журнал действий, текстовый лог.

## Технологии

- **Backend**: Python 3.9+, Flask 3, SQLAlchemy 2, Flask-Login, Flask-WTF, pandas.
- **Frontend**: Jinja2, Bootstrap 5, Bootstrap Icons, немного JavaScript.
- **Хранилище**: SQLite (в Docker — именованный том).
- **Сервер**: waitress; Docker и docker compose — см. Фазу 15 в `PLAN.md`.

## Быстрый старт

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # Windows; в Linux: cp .env.example .env
python init_db.py           # создаёт college.db и первого администратора
python run.py               # http://127.0.0.1:5000
```

Подробная инструкция, включая настройку `.env`, порта и Docker, — в `zapusk.txt`.

## Структура проекта

```
app/
  init_.py        создание приложения, БД, вход в систему, заголовки безопасности
  models.py       модели SQLAlchemy
  routes.py       все маршруты (/students, /journal, /schedule, /results, ...)
  forms.py        формы и валидация
  utils.py        импорт, выгрузка, бэкапы, выборки для журнала, аудит
  templates/      Jinja2-шаблоны
config.py         настройки из переменных окружения (.env)
migrations.py     создание и обновление схемы БД
init_db.py        первичное наполнение базы
create_admin.py   создание администратора (нужен ADMIN_PASSWORD в .env)
run.py            запуск (waitress или сервер разработки)
tests/            тесты pytest: conftest.py и 7 наборов
```

Рабочие файлы создаются рядом с проектом: `college.db`, `backups/`, `exports/`,
`logs/`, `uploads/`. Пути переопределяются переменными `DATABASE_URL`,
`BACKUP_FOLDER`, `EXPORT_FOLDER`, `LOG_FOLDER`, `UPLOAD_FOLDER`.

## Тесты

```
pip install -r requirements-dev.txt
pytest                       # весь набор
pytest tests/test_journal.py # отдельный файл
```

94 проверки, каждая работает на своей копии базы во временном каталоге:
`conftest.py` собирает её один раз и копирует перед тестом, так что тесты не
зависят от порядка и не трогают рабочие данные.

Наборы: `test_auth` (вход, блокировка, смена пароля), `test_crud`,
`test_journal`, `test_accounts`, `test_security` (CSRF, права, IDOR, заголовки),
`test_data` (импорт, выгрузка, бэкапы, цикл восстановления), `test_routes`
(обход всех маршрутов, проверка, что GET на POST-маршрутах даёт 405).
