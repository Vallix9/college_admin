# College Admin - Система управления учебным процессом колледжа

Веб-приложение для администратора учебного отдела колледжа с функциями учета студентов, успеваемости и генерации отчетов.

## 🚀 Возможности

- 📊 Управление студентами (добавление, редактирование, удаление)
- 🔍 Расширенная фильтрация студентов (по группе, полу, статусу)
- 👥 Управление учебными группами
- 📈 Учет успеваемости (выставление оценок)
- 📁 Генерация отчетов в Excel
- 🎨 Чистый минималистичный интерфейс
- 🔐 Авторизация администратора

## 🛠 Технологии

- **Backend**: Python 3.9+, Flask, SQLAlchemy
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Database**: SQLite (легко переключить на MySQL/PostgreSQL)
- **Дополнительно**: Pandas для экспорта в Excel, Docker для контейнеризации
